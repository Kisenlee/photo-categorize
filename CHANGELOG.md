# Changelog

All notable changes to this project are documented in this file.

## [1.0.1] - 2026-09-27

### Added

- `A` / `D` for previous / next image (arrow keys still work).
- Filmstrip under the preview: 5 previous, current, and 5 next thumbnails; click to jump.

## [1.0.0] - 2026-09-27

### Added

- Initial release, adapted from video-categorize for images (jpg, jpeg, png, gif, webp, bmp, avif).
- Classify copies into category folders; the original stays in the inbox and the view advances to the next image.
- Single (`Q`) and multi (`E`) modes; `Space` confirms multi-classify, or skips the current image when there is nothing to copy.
- `←` / `→` previous / next image; image fits inside the window.
- Favorite (`F`) also copies into `Favs`; revert (`R`) deletes the copies (up to 5 records).
