# Photo Classifier（图片分类助手）

Windows 桌面小工具：逐张预览本地 / NAS 待处理文件夹中的图片，一键**复制**到目标文件夹下的分类子目录。原图始终保留在待处理文件夹。

由 [video-categorize](https://github.com/Kisenlee/video-categorize) 改编而来，面向图片。

## 功能

- **目标文件夹即分类**：目标文件夹的一级子目录就是分类列表，在资源管理器中新建/删除文件夹会实时刷新（`Favs` 与 `.` 开头的目录不显示）。
- **复制而非移动**：分类时复制到目标子目录，原图保留，处理完自动进入下一张。
- **单类 / 复类模式**
  - 单类（`Q`）：点击分类或按绑定键，立即复制进去并进入下一张。
  - 复类（`E`）：勾选多个分类后按 **空格** 一次性复制到所有已勾选分类。
- **空格跳过**：没有可复制目标时（单类模式，或复类模式未勾选），空格跳过当前图片。
- **重命名**：左侧可修改复制后的文件名（不含扩展名），同名自动加 `_1`、`_2` 后缀。
- **收藏**（`F` / 顶部 ★）：开启后额外复制一份到 `目标/Favs`，每次分类后自动关闭；开启收藏时即使未选分类，空格也会仅复制到 Favs。
- **撤销**（`R`）：删除上一次复制出的文件并回到该图片，最多保留 5 条记录。
- **按键绑定**：分类右侧按钮点击后按 `1–0`、`W S Z X C` 绑定，再点清除。
- **缩略图条**：大图下方显示前 5 张、当前、后 5 张，点击跳转。
- **序号跳转**：顶部输入序号回车跳到第 N 张；窗口获得焦点时自动重扫待处理文件夹。
- 中文 / English 界面切换。

支持格式：jpg、jpeg、png、gif、webp、bmp、avif。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| 空格 | 复类：复制到已勾选分类并下一张；无目标时跳过 |
| A / ← | 上一张 |
| D / → | 下一张 |
| Q / E | 单类 / 复类模式 |
| F | 切换收藏 |
| R | 撤销上一次分类 |
| 1–0、W、S、Z、X、C | 触发已绑定分类（单类：直接复制；复类：勾选/取消） |

## 开发

需要 Node.js 20+。

```bash
npm install
npm run dev        # 开发模式
npm run typecheck  # 类型检查
npm run dist:win   # 打包 Windows portable exe 与 zip，输出到 release/
```

NAS 目录分类列表不刷新时，可设置环境变量 `PHOTO_CLASSIFIER_POLL=1` 启用轮询。
